# Simple Crud

Um projeto exemplificando as operações de um CRUD em uma interface web (CREATE, READ, UPDATE, DELETE).




## Autor

- [@GabrielPradoC](https://github.com/GabrielPradoC)


## Funcionalidades

- Adição de cards
- Atualização de cards
- Remoção de cards
- Listagem de cards


## Tech Stack

**Cliente:** HTML, CSS, Javascript, Typescript

## Instalação
 É necessário ter o git instalado em sua máquina para clonar o repositório

```bash
  git clone https://github.com/GabrielPradoC/simple-crud.git
```

Depois basta abrir o arquivo index.html que se encontra na raiz do projeto em seu navegador
  
Este projeto também está disponível para ser acessado [clicando aqui](https://gabrielpradoc.github.io/simple-crud/)
